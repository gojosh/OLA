# Session log

One file per working session: `YYYY-MM-DD-short-topic.md`. Newest is the one to read first. Keep entries short; the docs hold the substance, the log tells the next agent what happened.

## Template

```markdown
# YYYY-MM-DD — <topic>

**Agent/tool:** <e.g. Claude Code (Opus 5.5)>

## What happened
- …

## What changed
- Files created, moved, or materially edited.

## Open threads
- What the next session should pick up; links to open-questions items.
```
