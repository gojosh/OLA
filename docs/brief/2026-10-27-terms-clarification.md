# Traditional, not antiquated — 2026-10-27

Great questions - to be clear, I'm not asking us to use antiquated language, rather to use traditional terms. "Holy Unction" is archaic, and no longer in use, but that is exactly the right type of question. Half the time, we'll pick the older term, some are no longer in use.
