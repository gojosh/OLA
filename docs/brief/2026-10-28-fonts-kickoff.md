# Font creation kickoff — 2026-10-28

Great. Let's start talking font creation. Now that we have proper references, what's a good way to go about this? Let's discuss. Clearly some of the glyphs are antiquated, and will need to be contextual alternates. We have shape primitives within characters which repeat - what's the proper approach there - assemble and tweak characters from these refined primitives? On plate A, the lowercase letters have what should be contextual alternates, without plain versions, but we should easily be able to extrapolate to the plain versions. I want clean refined lines everywhere - the target is not a rapidly made, low quality grunge font. How can we take advantage of this era of bespoke software to radically accelerate the creation of ultra-high quality Pugin fonts?
