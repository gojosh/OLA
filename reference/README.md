# Reference

Outside source material to learn from: historical works, photographs, precedents. Not templates.

## Conventions

- One folder per source, `kebab-case`, with a `README.md` covering: what it is, where it came from, rights/attribution, and a catalog if it's a set.
- Keep originals. If agents or browsers can't open the original format (`.jp2`, `.heic`, `.tif`, `.psd`…), add web-viewable previews (`previews/`, JPEG, ~1200 px) and, for large sets, a contact sheet.
- Note rights clearly. Public-domain works are fine to use; anything else needs a note on permission.
- Never add photographs of identifiable parishioners (especially minors) without documented consent.
