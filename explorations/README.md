# Explorations

Concept work made for this project: studies, sketches, prototypes. **Not a codebase to build on** (decision [0002](../docs/decisions/0002-existing-concepts-are-reference-not-foundation.md)).

## Conventions

- One folder per exploration, `kebab-case`.
- Prefer self-contained artifacts (a single HTML file, images) that open without a build step.
- Every exploration has a `NOTES.md` with:
  - **What it is:** date, who or what made it, what question it was exploring.
  - **Verdict:** Josh's reaction, quoted where possible, kept separate from the agent's assessment.
  - **Keep / avoid:** ideas that carry forward and ideas to drop.
- Ideas carry forward only once restated in a foundation doc or a decision record.
- Placeholder content in explorations must look like placeholder content (AGENTS.md §4.4).
