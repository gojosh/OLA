# Our Lady of the Atonement — Website

The overhaul of the website for Our Lady of the Atonement, a Catholic parish of the Personal Ordinariate of the Chair of St. Peter in San Antonio, Texas.

The aim: the best Catholic parish website ever made. English-Catholic in spirit, Gothic by inheritance, American by home, and governed throughout by a logic that gives every element a reason to be there.

**Status:** Phase 0 — Foundations. No code yet. See [`docs/roadmap.md`](docs/roadmap.md).

## Start here

- **People:** read [`docs/foundations/01-vision.md`](docs/foundations/01-vision.md), then the rest of `docs/foundations/` in order.
- **AI agents:** read [`AGENTS.md`](AGENTS.md). It covers reading order, rules, and conventions.
